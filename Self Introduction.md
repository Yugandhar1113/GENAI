### Project 1: AI-Powered Document Q&A System
### Problem Statement
Retrieving specific, context-relevant information from large document collections is slow and inefficient using traditional keyword search.

Lack of contextual understanding in search results leads to incomplete or irrelevant answers.

### Motivation
--Reduce manual effort in searching documents.
--Provide accurate, context-aware answers instantly.
--Leverage Generative AI to improve productivity and decision-making speed.

### Technologies Used
--Python, LangChain, GPT-4, OpenAI APIs, FastAPI, ChromaDB, Sentence Transformers, PyPDF2/pdfplumber, Postman

### Detailed Approach
1.Data Ingestion – Built a pipeline to read and chunk documents (PDF, TXT).
2.Vector Embeddings – Generated embeddings using Sentence Transformers.
3.Vector Store – Stored embeddings in ChromaDB for fast semantic retrieval.
4.Retrieval-Augmented Generation (RAG) – Used LangChain to retrieve context and GPT-4 to generate answers.
5.API Development – Created a REST API with FastAPI for integration with external apps.
6.Testing & Optimization – Conducted accuracy checks, latency optimization, and relevance validation.

### Challenges Faced
--Ensuring context retrieval accuracy for long documents.=
--Managing performance when processing large document datasets.
--Optimizing GPT-4 API calls to reduce latency and costs.

### Impact
--Reduced document search time from minutes to seconds.
--Delivered high-accuracy, context-aware answers.
--Enabled seamless integration into enterprise systems via APIs.

### Project 2: Customer Churn Prediction for a Telecom Company
### Problem Statement
--High customer churn impacts business revenue and growth.
--Lack of predictive insight into which customers are likely to leave.

### Motivation
--Enable proactive customer retention strategies.
--Improve business decision-making with data-driven churn prediction.

### Technologies Used
--Python, Scikit-learn, Pandas, Matplotlib, Logistic Regression, XGBoost, GridSearchCV

### Detailed Approach
1.EDA – Identified churn patterns and anomalies.
2.Feature Engineering – Applied one-hot encoding, feature scaling, and missing value handling.
3.Model Training – Compared Logistic Regression and XGBoost models.
4.Hyperparameter Tuning – Used GridSearchCV to optimize AUC and precision-recall scores.
5.Visualization – Created dashboards to show churn drivers and model results.

### Challenges Faced
--Handling class imbalance between churn and non-churn customers.
--Ensuring model interpretability for business stakeholders.

### Impact
--Achieved high AUC score for churn prediction.
--Provided actionable insights for targeted retention campaigns.
